Syncs tasks with due dates to your Google Calendar as all-day events. You need a free Google Cloud OAuth Client ID — it takes about 2 minutes to set up.

▶ How to get a Client ID (2 min)
  1. Open console.cloud.google.com
  2. Create a project (or pick an existing one)
  3. Go to APIs & Services → Library → enable Google Calendar API
  4. Go to Credentials → Create → OAuth client ID
  5. Choose Web application
  6. Under Authorized JavaScript origins add http://localhost and your file's URL
  7. Copy the Client ID and paste it above
